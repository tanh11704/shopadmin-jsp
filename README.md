# ShopAdmin — JSP/Servlet training

Ứng dụng Java đóng gói WAR, dùng Jakarta Servlet 6.0 và JSP/JSTL.

## 1. Cài đặt

- JDK 21; đặt `JAVA_HOME` trỏ tới JDK 21.
- Apache Maven 3.9.x.
- [Apache Tomcat 10.1.x](https://tomcat.apache.org/tomcat-10.1-doc/index.html), hỗ trợ Servlet 6.0. Tải bản Binary Core và giải nén.
- PostgreSQL và công cụ dòng lệnh `psql`.

Kiểm tra môi trường:

```sh
java -version
mvn -version
psql --version
```

Các lệnh dưới đây dùng shell macOS/Linux và chạy từ thư mục chứa `pom.xml`.

## 2. Tạo database PostgreSQL

Khởi động dịch vụ PostgreSQL theo cách cài đặt trên máy, sau đó đăng nhập bằng tài khoản quản trị (thay `postgres` nếu cần):

```sh
psql -h localhost -U postgres -d postgres
```

Chạy SQL trong `psql`:

```sql
CREATE USER shopadmin WITH PASSWORD 'CHANGE_ME';
CREATE DATABASE shopadmin OWNER shopadmin;
\q
```

Thay `CHANGE_ME` bằng mật khẩu riêng. Kiểm tra kết nối:

```sh
psql -h localhost -U shopadmin -d shopadmin -c 'SELECT current_database(), current_user;'
```

Listener khởi động truy vấn bảng `category`. Với database mới, đăng nhập bằng tài khoản ứng dụng và tạo bảng tối thiểu trước khi chạy:

```sh
psql -h localhost -U shopadmin -d shopadmin
```

```sql
CREATE TABLE IF NOT EXISTS category (
    id BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
    name VARCHAR(255) NOT NULL,
    active BOOLEAN NOT NULL DEFAULT TRUE
);
\q
```

Đây là cấu trúc tối thiểu phục vụ `CategoryDAO` hiện tại, chưa phải schema đầy đủ cho các chức năng quản lý sản phẩm.

## 3. Cấu hình kết nối database

Tạo file `src/main/resources/db.properties` (file này đã được bỏ qua trong `.gitignore`):

```properties
db.url=jdbc:postgresql://localhost:5432/shopadmin
db.username=shopadmin
db.password=CHANGE_ME
db.pool.max=10
```

Điền đúng mật khẩu đã đặt ở bước 2. Nếu file đã tồn tại, chỉnh giá trị theo môi trường của bạn.

PostgreSQL JDBC driver đã được khai báo trong `pom.xml` và được Maven đóng gói vào `WEB-INF/lib` của WAR. `AppStartListener` đã có `@WebListener`, tự tạo connection pool và tải danh mục khi deploy; database phải sẵn sàng trước khi chạy Tomcat.

## 4. Build và chạy

Build WAR:

```sh
mvn clean package
```

Kết quả nằm tại `target/training.war`. Deploy vào Tomcat đã giải nén:

```sh
export CATALINA_HOME="/duong/dan/apache-tomcat-10.1.x"
cp target/training.war "$CATALINA_HOME/webapps/"
sh "$CATALINA_HOME/bin/catalina.sh" run
```

Tomcat chạy ở foreground; nhấn `Ctrl+C` để dừng. Mặc định truy cập:

- Trang chủ: <http://localhost:8080/training/> — hiển thị `Hello World!`.

Nếu chạy bằng IntelliJ với Application context `/shopadmin`, truy cập <http://localhost:8080/shopadmin/>. Sau khi đổi dependency, chọn **Reload All Maven Projects**, build lại artifact và restart Tomcat.

Sau khi sửa mã, dừng Tomcat, chạy lại `mvn clean package`, chép lại WAR và khởi động Tomcat. Các JSP trong `WEB-INF/views` cần controller forward tới; hiện chưa có servlet `/products`.

## 5. Xử lý lỗi thường gặp

- `invalid target release: 21`: kiểm tra `mvn -version` đang sử dụng JDK 21.
- HTTP 404: kiểm tra WAR đã deploy, context path là `/training`, và log khởi động Tomcat có lỗi hay không.
- `No suitable driver`: reload Maven, build lại và kiểm tra artifact chứa `WEB-INF/lib/postgresql-*.jar`, sau đó restart Tomcat.
- `StaticLoggerBinder`: kiểm tra artifact chỉ chứa SLF4J API 2.x để tương thích Logback 1.5; reload Maven và build lại artifact để cập nhật dependency.
- Không tìm thấy `/db.properties`: tạo file đúng đường dẫn ở bước 3 rồi build lại.
- Lỗi kết nối database: kiểm tra PostgreSQL đang chạy, cổng, tên database, tài khoản và mật khẩu bằng lệnh `psql` ở bước 2.
- Cổng 8080 đang được sử dụng: dừng tiến trình đang chiếm cổng hoặc đổi cổng trong `conf/server.xml` của Tomcat.
